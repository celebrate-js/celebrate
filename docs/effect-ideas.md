# エフェクト案リスト（ブレスト・未実装）

「[ゲーム的リアクションの分類法](reaction-taxonomy.html相当)」の4方式（単品／ボーダー／画面全体／ナラティブ）ごとに、
思いつく限り並べたもの。**全部未実装のアイデア出し**。実装するかは別途選定する。

方針の再確認（実装するときのために）：

- 単体絵文字は使わない（GlyphBurstのような「複数個が散る」用途のみ絵文字OK）
- 実装は既存のCSS/SVGパターン（clip-path, box-shadow多重, conic-gradient, stroke-dasharray等）を優先し、画像アセットは使わない

## ⑤ 段階エフェクト（時間軸で姿を変える／閾値でガクッと切り替わる）

`intensity`（連続スケーリング：滑らかに大きく・強くなる）とは別物。
こちらは**明確な「ステージ」を順番に踏む**演出、または**閾値を跨ぐと見た目が別物に切り替わる**演出。
「ヒビが入る→広がる→画面全体がバキバキ→崩れ落ちる」のように、**1回の発火の中で複数の局面がある**のが特徴。

### 単発の中に複数ステージがあるもの（時間軸型）

| 案                 | 内容                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| 画面ひび割れ崩壊   | ①中心にヒビが入る→②ヒビが画面全体に広がる→③バキバキと音が増える→④破片が崩れ落ちて次の場面が覗く（画面全体・4段階） |
| 氷結→粉砕          | 対象が凍りついていく→表面が真っ白に→パリンと砕けて破片が飛ぶ                                                       |
| 充填→解放          | ゲージが右から満ちていく→満タンで一瞬静止（溜め）→弾ける                                                           |
| 開花シーケンス     | つぼみ→ふくらむ→花びらが1枚ずつ開く→満開で静止                                                                     |
| 変身シーケンス     | 光に包まれる→輪郭がぼやける→新しい形のシルエット→ディテールが戻る                                                  |
| 崩落カウントダウン | 警告点滅→ひび割れ音のタイミングでシェイク増加→最後に崩落                                                           |
| 建設プロセス       | 土台が組まれる→骨組みが立つ→壁が現れる→完成して光る                                                                |
| 溶解               | 対象の輪郭が滲み始める→液状に崩れる→水たまりになって消える                                                         |
| 巻物が開く         | 紐がほどける→クルクルと巻物が広がる→中身の絵/文字が現れる                                                          |
| 稲妻から炎上       | lightningが着弾→着弾点がチリチリ焦げる→炎が上がる（lightningの発展系）                                             |
| 波紋の連鎖         | 1つの波紋→到達点でまた波紋→また波紋、と輪が輪を呼ぶ                                                                |
| 夜明け             | 画面が徐々に暗→薄明→朝日が差し込む（複数variantのグラデーション遷移）                                              |

### 閾値でランクが切り替わるもの（離散ティア型）

| 案             | 内容                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------- |
| メダルランク   | 銅→銀→金→虹色、と閾値ごとにバッジの意匠そのものが差し替わる（色を混ぜるのではなく別デザインに切替） |
| コンボ色分け   | combo 1-4=白, 5-9=青, 10-19=紫, 20+=金、のように帯で見た目がジャンプする                            |
| 星の確定表示   | ★☆☆ → ★★☆ → ★★★ と、埋まる星の数が段階ごとに増える（連続scaleではなく個数）                         |
| ランクプレート | C→B→A→S→SS、とプレートの絵柄ごと差し替え                                                            |
| 信号進行       | 赤→黄→緑、と離散的に色が切り替わって「進め」を示す                                                  |
| 天井予告       | 「あと1回で確定演出」のような、閾値の1つ手前だけ専用の予告カットが挟まる                            |
| 進化形態       | 卵→ひよこ→鳥のように、連続変形ではなく形態そのものが飛び飛びに変わる                                |
| ダメージ表情   | 満タン→ひび→大破、のように対象の見た目が閾値ごとに3段階で変わる                                     |

### 実装のヒント

- 時間軸型はCSSの`@keyframes`に複数の`%`ステップを刻めば1つのvariantで完結できる（`celebrate-lightning-flicker`と同じ考え方の延長）
- 離散ティア型は`rollRewardTier`と似ているが、**乱数ではなく「渡された値がどの区間に入るか」で分岐する**関数が必要（`tierForValue(value, thresholds)`のようなヘルパーが要りそう）
- 「崩壊」「溶解」のような複数ステージものは、既存の`isFullScreenContent`（rain/lightning）の仕組みが使えそう

## メモ

- 数が多いカテゴリ（①単品）は既に14個実装済みなので、次に手薄な**④ナラティブ**（現状2個）から拡充するのが優先度高そう
- ③画面全体は既に5個あるが、実装コストが高い割に「同時に画面全体は1つしか出せない」制約もあるので、選定は絞ったほうがよさそう
- ②ボーダーは第3のAPI（`useCelebrateBorder`）で独立しているので、他カテゴリと違い「既存要素を装飾する」文脈が必要（デモの使い方も変わる）
- ⑤段階エフェクトは「時間軸型」と「離散ティア型」で実装方式が全く違う（前者はCSSだけ、後者は値→区間のマッピング関数が要る）ので、着手時にどちらから作るか決めた方がよさそう。**画面ひび割れ崩壊**は時間軸型の分かりやすい第一候補
